## 功能
- v1 🎉
  - 1、对单条数据支持勾选、支持点击；✅
  - 2、支持复制已选数据；✅
  - 3、清空已选数据；✅
- v2（开发进行中...）👏
  - 1、支持数据的动态监听 ✅（2025-11-13）；
  - 2、支持框选 ✅（2025-11-13）；
  - 3、操作模块：样式优化 tailwind css + react✅（2025-11-17）；
  - 4、操作模块增加：启用、停用模式✅（2025-11-17）；
  - 5、popup：优化样式，一键导出md；
  - 6、正式发布插件\图标激活；
- v3（开发进行中...）👏
  - 支持国际化
  - 支持其他格式：html、pdf等；
  - 支持嵌套元素遍历转化；
  - 操作模块：可拖动；
  - 增加快捷键；
  - 以及支持发送到对应文件夹（一键生成博客）；
  - 支持查看排序；

| 导出方式             | 技术方案                          |
|--------------------|-----------------------------------|
| 复制到剪贴板         | `navigator.clipboard.writeText()` |
| 保存为 Markdown 文件 | Blob + FileSaver.js               |
| 发送到 Obsidian      | `obsidian://new?` protocol        |
| 发送到 Notion        | Notion API (可选)                 |
| 导出 GitHub Gist     | GitHub API                        |
